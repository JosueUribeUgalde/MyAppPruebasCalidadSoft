# MyAppPruebasCalidadSoft

Proyecto desarrollado para la materia de **Pruebas y Aseguramiento de Calidad del Software**.  
Aplicación móvil construida con **React Native** y **Expo SDK 54**, orientada a practicar conceptos de pruebas y aseguramiento de calidad en el desarrollo de software.

---

## Requisitos previos

Asegúrate de tener instalado lo siguiente antes de ejecutar el proyecto:

- [Node.js](https://nodejs.org/) (versión 18 o superior)
- [Git](https://git-scm.com/)
- [Expo Go](https://expo.dev/client) en tu dispositivo móvil (opcional, para pruebas físicas)

---

## Clonar el repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
cd MyAppPruebasCalidadSoft
```

---

## Instalar dependencias

```bash
npm install
```

---

## Ejecutar el proyecto

### Iniciar el servidor de desarrollo
```bash
npx expo start
```

### Correr en Android
```bash
npx expo start --android
```

### Correr en iOS
```bash
npx expo start --ios
```

### Correr en navegador web
```bash
npx expo start --web
```

> Después de ejecutar `npx expo start`, escanea el código QR con la app **Expo Go** desde tu dispositivo móvil para visualizar la aplicación.

---

## Tecnologías utilizadas

- React Native `0.81.5`
